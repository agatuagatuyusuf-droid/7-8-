--------------------------------------------------------------------------------

  ├── autodoor_behavior_tree.code-workspace   VS Code 工作区配置（旧名称兼容）
  ├── build.bat                  一键重新打包脚本
  ├── build_config.json          构建配置
  ├── generate_build_info.py     生成构建信息脚本
  ├── main.py                    程序入口
  ├── requirements.txt           Python 依赖列表
  └── README.md                  项目说明文档


二、直接用：不用改代码，拿来就用
--------------------------------------------------------------------------------
1. 解压本压缩包。
2. 进入目录：
      AutoDoorPro/dist/autodoor-pro-1.6.0/
3. 双击运行：
      autodoor-pro.exe
4. 该目录下已包含所有运行所需的驱动和资源。


三、想修改：从源码运行
--------------------------------------------------------------------------------
1. 安装 Python 3.12 或更高版本（建议 3.12）。
2. 解压后进入项目目录：
      cd AutoDoorPro
3. 安装依赖（推荐使用虚拟环境）：
      python -m venv venv
      venv\Scripts\activate
      pip install -r requirements.txt
4. 运行程序：
      python main.py


四、修改代码后重新打包
--------------------------------------------------------------------------------
1. 确保依赖已安装，且 PyInstaller 已安装：
      pip install pyinstaller
2. 双击运行或在命令行执行：
      build.bat
   打包完成后，新的可执行文件会生成在：
      dist/autodoor-behaviortree-<版本号>/


五、推荐开发方式
--------------------------------------------------------------------------------
- 使用 VS Code 打开：
    AutoDoorPro.code-workspace
  这样会自动加载推荐的工作区配置。
- 主要业务代码在 bt_nodes/、bt_core/、bt_gui/、bt_utils/ 中。
- 新增节点可参考 bt_nodes/actions/ 或 bt_nodes/conditions/ 中的现有实现。
- 详细设计文档见 doc/ 目录。


六、注意事项
--------------------------------------------------------------------------------
- 本项目面向 Windows 平台，部分功能依赖 Windows API 与驱动。
- 运行时如果杀毒软件报毒，通常是 DD64.dll / IbInputSimulator.dll 等
  输入模拟驱动被杀毒软件误报，请自行添加信任。
- 修改代码前建议先确认 requirements.txt 中的依赖版本，尤其是：
      onnxruntime==1.19.0
  版本不一致可能导致 OCR 功能异常。
